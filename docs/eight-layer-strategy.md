# 八层策略配置

策略实现位于 `services/selector/strategies/eight_layer_strategy.py`，严格对应用户提供的八层规则：市场总闸门、热点板块、质量过滤、可买性一票否决、技术共振、资金验证、溢价评估、总分排序。

实时供应商适配器必须在北京时间 14:35 提供：三大指数及 MA20、全市场涨跌和涨跌停统计、连续活跃板块、板块成份、ST/退市/解禁/PE、行情指标、技术形态、当日及五日主力资金、14:00–14:40 资金数据和近 20 日涨停记录。

缺失任一核心字段时任务状态为 `blocked`，不发布推荐标的。市场环境为“空仓”时任务状态为 `cash`，页面仅展示“今日市场环境恶劣，建议空仓观望”。
